# 立体书制作技巧总结

做《Memory in London》时用过、验证过的做法，加上补充的技巧，按制作顺序分成九部分：折纸结构、小机关、视觉设计、叙事与节奏、照片变立体页、网页立体书、打样与生产、补充技巧、检查清单。

- 参考书和案例见 [research-notes.md](research-notes.md)
- 生图 prompt 版见 [popup-book-skills.md](popup-book-skills.md)

文中“书页”指一页的平面，单位和引擎一致：一页宽 100、深 130（书脊在 X=0，上下边缘 Z=±65）。

---

## 〇、做一页的顺序

1. **定主角**：这一页最想让人记住的一样东西（蓝鲸、大本钟、塔桥）。
2. **按主角选结构**：先问“它是什么形状、怎么动”，再挑折法（见第一部分末尾的“按主题选结构”）。
3. **排层次**：远景、中景、主角、前景、地面，一共五层，每层离书脊的距离不同。
4. **加一个机关**：让主角或和主角有关的东西动起来。
5. **画面**：底页先画（地面就是一幅画），再画每张纸片，最后补文字卡。
6. **检查**：合书能不能收进去、有没有悬空、动作做不做得出来（`paper-check.js`）。
7. **试玩和打样**：网页里每个机关来回操作，实体用白卡纸打一版。

## 一、折纸结构

### 1. 三条铁律

| 规则 | 说法 | 检查方法 |
|---|---|---|
| **合书收得进** | 合上时每张纸片都在页面范围内：离书脊的距离 + 纸片高度 ≤ 页高。打开时可以伸出页边。 | 把纸片按倒下的方向平放，看四个角在不在页内 |
| **不越过书脊** | 单页上的纸片合书时不能倒到对页去 | 倒下后 X 的符号不变 |
| **每片都有根** | 每张纸片要么底边粘在页面上，要么铆/粘在另一张纸片上；不能悬空 | 离开页面的部件必须写明附着在谁身上 |

还有两条容易忘：

- **只能做纸能做的动作**：纸片不会自己上下浮动、摇晃；V 折的角度不会自己变。动作只能来自开合书、拉片、转盘、手指。
- **背面会被看见**：立起来的纸片、翻转的卡片、拱桥的内侧都会露出背面。要么双面印刷，要么背面印成合理的样子。塔桥右半边曾经露出白纸，就是这个原因。

### 2. 倒向规则（平行折）

- **面向读者的纸片**（底边横着放）：合书时**向前倒**，由背后的撑条连到对页拉起。
- **沿街的侧墙**（底边顺着书脊方向）：合书时**向外倒**（远离书脊），撑条跨过书脊。
- 两排侧墙相对时，各自向外倒，中间的街道留空，巴士、人物放在街道上。
- 撑条在网页里默认不画，否则画面很乱。做结构图时再显示。

### 3. 结构库

| 结构 | 怎么立起来 | 关键尺寸 / 注意 | 用过的地方 |
|---|---|---|---|
| **平行折立片** | 底边铰接，开书时撑条把它拉直 | 离书脊距离 + 高 ≤ 页高 | 地铁站牌、路灯、小人、恐龙骨架 |
| **V 折** | 两条粘贴线与书脊成相同角度，跨书脊立起 | 角度越小越直立；左右翼长度可以不同；只能跨书脊 | 议会大厦长立面、街景背景、彩旗串 |
| **箱形折** | 方盒随开书展开 | 合书时盒深一半向前、一半向后摊平 | 87 路巴士、卡片盒 |
| **十字插片** | 两片开槽交叉，开书撑成四面 | 两片都要双面印刷 | 大本钟（早期版本）、小黄瓜 |
| **手风琴立面** | 长立面折成 Z 字 | 角楼落在折线上，折线就是建筑的转角 | 议会大厦（早期版本） |
| **连续平折建筑** | 侧墙 + 转角面连成一张纸，转角面铰接在侧墙端头，开书时翻出 90° | 转角面合书时折回贴着侧墙 | 西区两排房子和转角 |
| **附着子件** | 铆在或铰接在母纸片上，随母纸片一起折叠 | 坐标写在母纸片的坐标系里 | 钟面和指针、塔桥桥板、伦敦眼转轮、蓝鲸鳍 |
| **跨页大拱** | 一道拱跨过书脊连接左右页 | 拱内侧会被看到 | 塔桥上层走道 |
| **放射 / 烟花** | 纸片从中心向外放射 | 每条射线长度单独算合书约束 | 《伦敦地图》跨年夜 |
| **共用铰线的翻页叶片** | 几张卡片共用一条铰线，像台历一样往前翻 | 后翻下的要略平一点，才会叠在先翻下的上面 | 扉页卡片盒 |
| **藏在盒内、立起才升出的纸片** | 盒子折平时纸片藏在盒里，盒子立起后才从盒顶插槽升出 | 盒子折平时只看得到盒子的印刷面 | 扉页卡片盒 |

### 4. 常见错误（都踩过）

| 错误 | 表现 | 改法 |
|---|---|---|
| 合书伸出页边 | 高纸片离页边太近 | 往书脊挪，或改成侧墙、V 折 |
| 互相穿插 | 叶片往后翻，穿过后面的照片板 | 改翻转方向，或共用铰线 |
| 独立纸片拼建筑 | 一排房子是几张分开的纸 | 改成连续可平折的一张：侧墙 + 转角面 |
| 浮动、摇晃 | 为了“生动”让纸片自己动 | 动作挪给拉片或手指 |
| 白纸背面 | 翻起或拱起后露出没印的背面 | 双面印刷，或背面印成合理的样子 |
| 合起来什么都不剩 | 盒子折平时露出卡片内容 | 盖板 / 背面印成合上的盒子 |

### 5. 按主题选结构

| 主题 | 结构 | 理由 |
|---|---|---|
| 高塔、钟楼 | 平行折立片 + 附着子件（钟面） | 高、细，正面最重要 |
| 宫殿、长立面 | V 折跨书脊 | 横向展开，有透视感 |
| 街道 | 两排侧墙 + 转角面 + 远景 V 折 | 一点透视，像走进街里 |
| 桥 | 两塔立片 + 铰接桥板 + 跨页拱 | 开桥本身就是机关 |
| 大厅、室内 | 远墙 V 折 + 吊挂主角 + 前景展品 | 有天花板和纵深 |
| 车、船 | 箱形折 + 轨道 | 能沿轨道走 |
| 地图、路线 | 平铺底页 + 小建筑立片 | 告诉你在哪 |
| 收藏、记忆 | 卡片盒、信封、翻页小书 | 掀开即发现 |

## 二、小机关

### 1. 设计原则

1. **一定可逆**：拉出去能推回来，翻开能合上，开灯能关灯。翻页前所有机关自动复位。
2. **拉片放在它动的东西旁边**，跑在看得见的轨道槽里，轨道窄、方向明确。
3. **优先在画面里直接操作**：能拖纸片就不用拉片；能转转盘就不用按钮。拉片作为备选同时保留。
4. **一页一个主机关 + 一两个小彩蛋**，不要每样东西都能动。
5. **机关讲故事**：开桥是为了让船过，灯随船亮，船走灯灭；拨指针是为了让时间从下午走到黄昏。
6. **每个机关都要做得出来**：用卡纸、铆钉、拉条、滑槽实现，写不出实体做法的不做。
7. **提示要轻**：可点的东西轻轻发光呼吸，第一次点完就不再提示；不要靠大段说明文字。

### 2. 机关库

| 机关 | 实体做法 | 网页里的交互 | 用过的地方 |
|---|---|---|---|
| **拉片 + 轨道** | 页面开槽，纸条在槽里滑，末端连着要动的纸片 | 拉片或直接拖纸片 | 游船沿河、巴士前后开、两人碰面 |
| **转盘 / 曲柄** | 圆盘铆在页面上，露出一部分当把手，背面连杆带动 | 绕圈拖动 | 塔桥绞盘开桥 |
| **拨指针** | 指针铆在钟面中心 | 按住钟面绕圈拖 | 大本钟指针改时间 |
| **转轮** | 圆形纸片铆在支架上 | 点击转起 / 停下 | 伦敦眼 |
| **铰接翻板** | 纸片一边铰接，可抬起放下 | 联动拉片或转盘 | 塔桥两块桥板、SIX 招牌翻出 |
| **翻面卡** | 卡片中线铰接，正反两面 | 点击翻面 | 明信片、卡片盒 |
| **抽出** | 信封口袋，纸片在里面滑 | 拖出或点击 | 西区戏票 |
| **掀盖 / 小翻页** | 顶边铰接的翻盖、迷你书 | 点击 | 地名卡、扉页卡片盒盒盖 |
| **立起的盒子** | 箱形折 + 拉片控制立起角度 | 拉片 | 扉页卡片盒 |
| **出片** | 相机缝隙里抽出照片 | 点击 | 拍立得 |
| **摆动部件** | 小纸片铆在主体上，靠拉条摆动 | 点击 | 蓝鲸鳍 |
| **联动** | 一根拉条同时带两三件东西 | 一个机关驱动多处变化 | 船进桥开灯亮 |
| **开关灯（数字）** | 实体可用 LED + 导电墨水 | 点击切换夜景发光层 | 西区两排房子、伦敦眼 |
| **声音（数字）** | 实体可用发声模块 | 敲钟、快门声 | 大本钟“当”、拍立得“咔嚓” |

### 3. 做不出来、不要做的动作

- 纸片自己上下浮动、左右摇晃、呼吸缩放。
- V 折在书打开之后自己改变角度。
- 东西凭空出现、消失。可以从盒里升出、从口袋里抽出、翻面露出。
- 一根拉片带动不相连的东西又没有连杆。

## 三、视觉设计

### 1. 统一的画风

- **手绘水彩 + 墨线**：所有纸片用同一种描边（深墨色、略抖的线）和水彩填色，纸片边缘有毛边。
- **照着照片画，不直接贴照片**：保留辨识度最高的细节，比如大本钟的钟面、SIX 的灯泡框、《悲惨世界》的红旗和柯赛特、地铁站的红圈蓝条，其余简化。照片只在画中的照片里出现，比如拍立得、卡片盒的照片板。
- **人物统一**：同一个旅行小人贯穿全书（背包、发型、毛衣固定），朋友换配色。人物比例：电话亭约是人的 1.5 倍。
- **卡通海报也用书里的人物画法**：圆脸、大眼、高光、腮红。
- **字不能被滤镜扭曲**：水彩滤镜只作用在形状上，文字、细小的脸放在滤镜外面。
- **字要在框里**：横幅、灯带、标签卡上的文字按框宽自动缩放（`textLength`），中文分行。

### 2. 底页即地面

- 底页是一整幅画（地图、河岸、街道、广场），纸片从里面“长出来”。
- 道路、河流、轨道从底页延伸到远景纸片上，接缝对齐。
- 投影是画面的一部分，灯光方向全书统一。

### 3. 景深与层次

| 层 | 离书脊 | 颜色 | 内容 |
|---|---|---|---|
| 远景 | 最远（贴近上边缘） | 淡、冷、偏灰蓝紫 | 天空、远处天际线 |
| 中景 | 中 | 中等饱和 | 主建筑 |
| 主角 | 视觉中心 | 最饱和、对比最强 | 一页一个 |
| 前景 | 近（下边缘） | 暖、清晰 | 人物、路灯、站牌、道具 |
| 地面 | 页面本身 | 跟主题色 | 地图、路面、水面 |

每层都要留空、镂空，让人看得到后一层。

### 4. 光和时间

- **一页一个时间**：早上、午后、金色傍晚、黄昏、夜。灯光预设跟着变。
- **夜景用发光层**：窗户、灯泡、霓虹、灯箱单独画一层，开灯时叠加发光。发光层只画会发光的东西，橱窗分成窗格，不要整块亮黄。
- **机关可以改变光**：拨指针时下午变黄昏，开桥时桥灯亮。

### 5. 文字与版式

- **地名卡**固定在左下角，三行：英文地名、英文副标、中文地名 + 时间，文字全部在框内。
- **站牌**只用真实的伦敦地铁站名，不加点击文字。
- **地名由人物说出来**：点小人，小人说“这里是……”，不额外挂说明牌。
- 页面上方工具栏只留“本页介绍”和“回到封面”。

### 6. 颜色

- 每页一个主色，比如自然史博物馆的暖石色、威斯敏斯特的金色、西区的夜蓝 + 灯光黄、塔桥的深蓝 + 金色灯。
- 品牌色、标志色照实画：伦敦巴士红、地铁红圈蓝条、SIX 的深蓝金色。
- 强调色克制，高潮页再用最亮的颜色。

## 四、叙事与节奏

1. **一条时间线**：一天从早到晚，每页标时间（10:00 → 15:00 → 19:30 → 22:00）。时间要和画面里的钟、光线一致。
2. **扉页是目录**：路线地图 + 每站一座小建筑 + 卡片盒（一站一张卡）。
3. **逐页升级**：机关和结构越来越大，最后一页（塔桥夜景）最壮观。
4. **一页三件事**：一个主角、一个主机关、一两个彩蛋（明信片背面的小发现、照片、戏票）。
5. **真实感来自细节**：真实站名、真实剧目、照片里看到的招牌，比如“STILL THE WORLD'S MOST POPULAR MUSICAL”。
6. **人物带着走**：旅行小人在每一页出现，用她的话串起故事。

## 五、照片 → 一页立体书

1. **读照片**：找主角、地点、时间（光线）、标志性细节、颜色。
2. **拆层**：把照片里的东西分到远景、中景、主角、前景、地面五层，决定哪些画成独立纸片，哪些画在底页上。
3. **选结构**：按主角的形状选（第一部分末尾的“按主题选结构”），每张纸片标出折法。
4. **选机关**：照片里有什么在动、会变化？车、船、灯、钟、门、水。挑一个做主机关。
5. **画**：底页 → 远景 → 主角 → 前景 → 文字卡，全部照着照片手绘成统一画风。
6. **检查**：合书约束、附着关系、背面、文字在框内。
7. **出图**：选一个能看到主角正面和层次的相机角度，配上和照片一致的光，渲染成图。

## 六、网页立体书特有的技巧

| 技巧 | 说明 |
|---|---|
| 真实开合 | 纸片按真实折纸几何随书页开合，不是淡入淡出 |
| 翻页 | 点书页右下角 / 左下角翻页，卷曲按圆柱模型计算；热区判定在平面书页上 |
| 提示 | 可点的东西轻轻发光呼吸；用过之后提示消失 |
| 触屏 | 手指按下的位置周围一圈都参与判定，细小的纸片设置为整块可点 |
| 复位 | 翻页、合书前，拉片归位、翻盖合上 |
| 隐藏件不可点 | 藏起来的纸片不能被点到 |
| 镜头 | 默认视角看得到整页；可以拖动转视角、缩放 |
| 性能 | 每张纸片一张贴图，尺寸按需要定，SVG 光栅化后缓存 |
| 检查脚本 | `paper-check.js` 检查合书伸出、越过书脊、悬空、找不到母纸片、不可能的动作 |
| 回归测试 | 每次改动后用无头浏览器把每个机关操作一遍，再截图对照 |

## 七、打样与生产

1. **刀模线规范**：
   - 切割线：实线（常用红色）
   - 谷折：虚线
   - 山折：点划线
   - 粘贴区：灰色填充，标出“粘到 ×× 上”
   - 铆钉位：小圆圈
2. **纸张**：
   - 立体件用 250–300 g 卡纸，底页可以更厚。
   - 折线先压痕再折。
   - 折线方向尽量顺着纸纹。
3. **粘贴片**：
   - 宽 5–8 mm。
   - 粘贴片藏在纸片背后或底下。
   - 双面胶比液体胶更不容易让纸起皱。
4. **公差**：
   - 合书后纸片离页边至少留 3–5 mm。
   - 多层纸片叠起来的厚度要算进去。
5. **白模打样**：先用白卡做一版只看结构，确认开合顺畅、没有穿插，再上画面。
6. **组装顺序**：从离书脊最远的层开始粘，主角最后粘。附着子件先装到母纸片上，再一起装到书页上。

## 八、补充技巧（项目里还没用到，值得加）

**结构**

| 技巧 | 说明 | 适合 |
|---|---|---|
| 浮动平台（floating layer） | 一块水平纸板由两侧立片撑在半空 | 屋顶、桥面、舞台、餐桌 |
| 插片网格（sliceform） | 两组开槽纸片交叉插成网格，开书时整体立起 | 穹顶、山体、球形 |
| 旋转圆盘出片（rotating pop-up） | 开书时纸片绕铆钉转出来 | 风车、摩天轮出场 |
| 拉起楼梯 / 台阶 | 多段平行折连成阶梯 | 楼梯、看台、梯田 |
| 立体文字 | 字母本身做成平行折或 V 折 | 标题页、站名 |
| 半透明层（硫酸纸） | 雾、玻璃、水面、夜空 | 河面倒影、温室 |
| 镂空剪纸 | 激光镂空花纹，透出后层 | 铁艺栏杆、教堂花窗 |

**机关**

| 技巧 | 说明 | 适合 |
|---|---|---|
| 百叶变换（transformation） | 拉片一拉，画面像百叶窗一样换成另一幅 | 白天变黑夜、旧貌变新颜 |
| 转盘开窗（volvelle with window） | 转盘上开窗，转动换出不同内容 | 一天的时间、四季、菜单 |
| 拉片旋转 | 拉片带着纸片绕铆钉转 | 挥手、敲钟、开门 |
| 杠杆摇臂 | 一根杆一端拉、另一端翘 | 跷跷板、吊桥、手臂 |
| 弹出惊喜（pop-out） | 掀开盖子，里面的纸片弹起来 | 礼物盒、宝箱 |
| 拉绳 / 悬线 | 细线连接两个纸片 | 风筝、吊车、晾衣绳 |
| 挖孔穿页 | 封面或前页开洞，翻页时一直能透过去看 | 窗户、望远镜视角 |
| 二维码 / 扫码 | 页面上印二维码打开音频或视频 | 导览、音乐剧片段 |

**视觉和叙事**

| 技巧 | 说明 |
|---|---|
| 全书母题 | 一个小标志每页都出现（比如一只鸽子、一张车票），让读者去找 |
| 颜色从无到有 | 前几页低饱和，高潮页突然给满色 |
| 平面知识页与立体页交替 | 一张一弛，知识放在翻页小书里 |
| 封面挖孔 + 封底彩蛋 | 第一眼就看到立体，最后一页有回响 |
| 社交分享图 | 原照片和立体页并排或上下对照，一眼看出“照片变成了立体书” |

## 九、检查清单

**结构**

- [ ] 合书时每张纸片都在页面内，离页边至少 3–5 mm
- [ ] 没有越过书脊的单页纸片
- [ ] 没有悬空的纸片；子件都写明附着在谁身上
- [ ] 合书时纸片之间不互相穿插
- [ ] 会被看见的背面都印了画
- [ ] 每个动作都能用纸、铆钉、拉条、滑槽做出来

**机关**

- [ ] 每个机关都可逆，翻页前自动复位
- [ ] 拉片在它动的东西旁边，有轨道
- [ ] 细小的纸片整块可点
- [ ] 提示轻，不靠大段文字

**画面**

- [ ] 画风统一（描边、水彩、纸边）
- [ ] 主角最饱和，远景淡、冷
- [ ] 时间、光线、钟面一致
- [ ] 文字全部在框内、没有被滤镜扭曲
- [ ] 站名、剧目、招牌都是真实的

**叙事**

- [ ] 一页一个主角、一个主机关、一两个彩蛋
- [ ] 旅行小人出现，地名由她说出来
- [ ] 本页介绍和操作提示和画面一致
