## 一、折叠结构

1. **平行折**：纸片与书脊平行，像舞台布景一层层立起。本项目的基础结构。
2. **V 折**：两条粘贴线与书脊成相同角度 α。α 越小越直立，越大越往后仰成扇面。可以 V 叠 V，越长越繁复（海鸟悬崖、珊瑚）。
3. **箱形折**：方盒随开书立起，墙、屋顶、内部都能表现（建筑、货架、姜饼屋）。箱体内放一排平行斜片可以做飞扶壁（巴黎圣母院）。
4. **多层舞台**：多排平行景片前后排开，每排都要镂空，才看得到后一层（雨林、拱门隧道）。
5. **十字插片**：两片开槽十字交叉，撑成四面立体，适合塔、龙卷风、仙人掌。
6. **手风琴立面**：长立面折成 Z 字，角楼落在折线上（卢浮宫）。
7. **金字塔 / 多面体**：开书时拉起多个斜面（玻璃金字塔、荣军院穹顶）。
8. **跨页大拱**：一道拱把左右两页连成一体（过山车、海蛇、彗星洞穴）。
9. **放射 / 爆炸**：纸片从中心向外放射（愤怒、烟花、彗星）。
10. **环形 / 球形**：嵌套圆环开书成球（浑天仪）。
11. **螺旋弹簧、纸带线条**：混乱、雨丝。
12. **悬线**：金线把两个元素连起来，同时是叙事线（神谕从天而降）。
13. **外伸**：打开时纸片可以伸出页面前缘（云海、海浪）。**合书约束只管合上的状态。**
14. **房间 / 旋转木马**：书开 90°/360° 形成房间角落。

## 三、视觉设计

1. **插画风格服从主题**：手抄本（宗教）、博物画（自然）、拼贴（儿童、美食）、丝巾印花（品牌）、城市地图（旅行）。
2. **底页和立体件是一幅连续的画**：底页是地面，立体件从中"长出来"。
3. **空气透视**：后层淡、冷、低饱和，前层艳、暖。
4. **轮廓即设计**：有机的模切边，镂空透光。
5. **文字固定放在角落的方卡片里**。
6. **一本书一种光**：柔和摄影棚光、自然窗光、暗背景聚光。
7. **投影也是画面的一部分**。
8. **白模**：只靠光影表现形体，适合建筑和网页。

## 四、结构与主题的关联

**好的立体书里，结构本身就在讲故事。**

| 主题 | 结构 | 为什么 |
|---|---|---|
| 天使 / 飞翔 | 高耸 V 折、悬线 | 向上、从天而降 |
| 天体 | 环形 / 转盘 | 循环运行 |
| 文化起源 | 从中心放射 | 从一个源头向外传播 |
| 雨林 | 多排高耸平行层 | 茂密 |
| 悬崖 | V 叠 V | 嶙峋 |
| 草原、沙漠 | 低矮宽阔、稀疏 | 空旷 |
| 发明 | 能动的机械 | 结构即知识 |
| 情绪 | 螺旋 / 线雨 / 放射 / 平缓 | 一种情绪一种结构 |
| 数数 | 每页多一个元素 | 节奏即内容 |
| 城市地标 | 地图底页 + 按建筑选结构 | 告诉你在哪里、长什么样 |
| 龙卷风 | 十字插片拧成旋涡 | 气流上卷 |
| 风暴海浪 | 浪片围住主体 | 被包围的危险 |

**节奏**：逐页升级，最后一个跨页最大最复杂；平面知识页与大立体页一张一弛。
**复用**：一个基础结构换上不同的画，就是新的一页。

## 五、设计流程（来自姆明的数字样稿）

1. 先画一幅完整的平面插画。
2. 用细线标出模切线，决定哪些元素拆成独立纸片。
3. 每片纸片在平面图里标出插槽和粘贴位置。
4. 打样，对照成品检查每层的遮挡关系。

这和本项目"照片 → 立体书"的流程对应：照片 = 平面插画，自动分割 = 模切线，再给每个元素分配结构和层深。
