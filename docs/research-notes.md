## 一、折叠结构

1. **平行折**：纸片与书脊平行，像舞台布景一层层立起。本项目的基础结构。
2. **V 折**：两条粘贴线与书脊成相同角度 α。α 越小越直立，越大越往后仰成扇面。可以 V 叠 V，越长越繁复（海鸟悬崖、珊瑚）。
3. **箱形折**：方盒随开书立起，墙、屋顶、内部都能表现（建筑、货架、姜饼屋）。箱体内放一排平行斜片可以做飞扶壁（巴黎圣母院）。
4. **多层舞台**：多排平行景片前后排开，每排都要镂空，才看得到后一层（雨林、拱门隧道）。
5. **十字插片**：两片开槽十字交叉，撑成四面立体，适合塔、龙卷风、仙人掌。
6. **手风琴立面**：长立面折成 Z 字，角楼落在折线上（卢浮宫）。
7. **金字塔 / 多面体**：开书时拉起多个斜面（玻璃金字塔、荣军院穹顶）。
8. **跨页大拱**：一道拱把左右两页连成一体（过山车、海蛇、彗星洞穴）。
9. **放射 / 爆炸**：纸片从中心向外放射（愤怒、烟花、彗星）。
10. **环形 / 球形**：嵌套圆环开书成球（浑天仪）。
11. **螺旋弹簧、纸带线条**：混乱、雨丝。
12. **悬线**：金线把两个元素连起来，同时是叙事线（神谕从天而降）。
13. **外伸**：打开时纸片可以伸出页面前缘（云海、海浪）。**合书约束只管合上的状态。**
14. **房间 / 旋转木马**：书开 90°/360° 形成房间角落。

## 三、视觉设计

1. **插画风格服从主题**：手抄本（宗教）、博物画（自然）、拼贴（儿童、美食）、丝巾印花（品牌）、城市地图（旅行）。
2. **底页和立体件是一幅连续的画**：底页是地面，立体件从中"长出来"。
3. **空气透视**：后层淡、冷、低饱和，前层艳、暖。
4. **轮廓即设计**：有机的模切边，镂空透光。
5. **文字固定放在角落的方卡片里**。
6. **一本书一种光**：柔和摄影棚光、自然窗光、暗背景聚光。
7. **投影也是画面的一部分**。
8. **白模**：只靠光影表现形体，适合建筑和网页。

## 四、结构与主题的关联

**好的立体书里，结构本身就在讲故事。**

| 主题 | 结构 | 为什么 |
|---|---|---|
| 天使 / 飞翔 | 高耸 V 折、悬线 | 向上、从天而降 |
| 天体 | 环形 / 转盘 | 循环运行 |
| 文化起源 | 从中心放射 | 从一个源头向外传播 |
| 雨林 | 多排高耸平行层 | 茂密 |
| 悬崖 | V 叠 V | 嶙峋 |
| 草原、沙漠 | 低矮宽阔、稀疏 | 空旷 |
| 发明 | 能动的机械 | 结构即知识 |
| 情绪 | 螺旋 / 线雨 / 放射 / 平缓 | 一种情绪一种结构 |
| 数数 | 每页多一个元素 | 节奏即内容 |
| 城市地标 | 地图底页 + 按建筑选结构 | 告诉你在哪里、长什么样 |
| 龙卷风 | 十字插片拧成旋涡 | 气流上卷 |
| 风暴海浪 | 浪片围住主体 | 被包围的危险 |

**节奏**：逐页升级，最后一个跨页最大最复杂；平面知识页与大立体页一张一弛。
**母题**：全书只用一个造型（如爱心），每页换一种结构来讲它的变化：简单 → 冲突（箭穿过心）→ 纠缠 → 圆满。
**颜色克制**：前面全用白或低饱和，最后一页才给强调色，高潮最有冲击力（《Hearts of Love》）。
**复用**：一个基础结构换上不同的画，就是新的一页。

## 五、设计流程（来自姆明的数字样稿）

1. 先画一幅完整的平面插画。
2. 用细线标出模切线，决定哪些元素拆成独立纸片。
3. 每片纸片在平面图里标出插槽和粘贴位置。
4. 打样，对照成品检查每层的遮挡关系。

这和本项目"照片 → 立体书"的流程对应：照片 = 平面插画，自动分割 = 模切线，再给每个元素分配结构和层深。

## 六、手工小机关（来自手账 / 礼物书的机关合集）

这些机关常见于手工礼物书和相册，结构简单、互动感强，适合放在大立体页的旁边做“小惊喜”。

| 机关 | 怎么动 | 适合讲什么 |
|---|---|---|
| 瀑布卡（单排 / 双向两排 / 三排） | 拉片一拉，一叠卡片依次翻落 | 时间线、一串照片、路线上的几站 |
| 摩天轮 / 转转相遇 | 转盘转动，两个元素转到一起 | 摩天轮、相遇、循环 |
| 抽拉站立 | 拉片拉出，平躺的纸片站起来 | 恐龙骨架、招牌、一束花“立起来” |
| 平行抽拉 / 抽拉相遇 | 两个贴纸沿槽相向滑动，最后碰到一起 | 两个人相遇、交换礼物 |
| 日历机关 | 指针转到某个日期 | 纪念日、出发日 |
| 爱心拱桥 | 一串小件连成拱，跨过书脊立起 | 桥、彩虹、拱门 |
| 三折窗户卡 / 四宫格 | 小门从中间向四周打开 | 窗户、相框、揭晓 |
| 手风琴 / W 展开卡 | 折成 Z 字或 W 字，拉开一节节立起 | 长卷照片、行李箱里的物件 |
| 小书本 / 左右翻翻 | 页面上再装一本可翻的小书 | 旅行手册、补充故事 |
| 云朵翻盖（三层） | 层层翻盖，一层比一层小 | 逐层揭晓的秘密 |
| 立体纷飞 / 照片墙 | 打开时一组卡片从中心弹出 | 合影墙、庆祝 |
| 海浪机关 | 几层浪片前后错开、随拉片起伏 | 河、海、船 |
| 立体旋转星星 | 星形纸片旋转展开 | 星空、魔法时刻 |
| 倒数日抽拉卡 | 拉片露出一个个数字 | 倒计时、纪念日 |
| 拍立得 | 从相机里抽出一张照片 | 放进自己拍的照片，最有纪念感 |
| 燃烧机关 | 一层纸“烧”开，露出下面的画 | 揭晓、转场 |

**用法上的几条经验：**

1. **一个机关讲一件事。** 机关要和那一页的故事对上：船配海浪，相遇配抽拉相遇，拍照配拍立得。
2. **拉的方向 = 动的方向。** 船沿河走，拉片就沿河拉；巴士朝读者开，拉片就往读者方向拉。
3. **车和人不要“滑”。** 车沿着地上的轨道槽走、开到路口停下，走的时候有一点起伏；人走路时一步一颠。
4. **地名交给人物说。** 站牌只用在真实存在的地铁站上，地名用小人的对话说出来，画面更干净。
5. **放自己的照片。** 拍立得、照片墙、小书本是最适合放用户照片的位置。
