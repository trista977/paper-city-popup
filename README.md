# 纸上城市 · Pop-up books

一个可以在浏览器里翻的立体书书架。

- 示例书《Memory in London》（`memory.html`）：「城市旅行」模板的典型样书，真 3D 横向翻开的精装书。书放在木桌上，可以拖动转视角、缩放；翻开封面后纸片按真实折纸几何立起，翻页时一页页折平、展开，灯光从早晨变到深夜。扉页是站立抽拉卡片盒（拉出拉片，卡片盒和照片板站起来，一站一张卡片可以向前翻），之后四个场景：自然史博物馆大厅（蓝鲸骨架 + 抽拉站立的恐龙）、威斯敏斯特（拍立得里是作者拍的大本钟，游船沿河拉动）、西区剧院街（抽拉相遇 + 沿轨道开的纸盒巴士）、塔桥之夜（开桥 + 海浪机关，拉到底全桥亮灯）。旅行小人用对话说出每一站的地名，站牌只保留真实的地铁站。
- 示例书《伦敦》：舞台式立体书，纸片按平行折的几何关系随书页开合立起、折平；页面上可以直接拉拉片、掀翻页、转转盘、点机关；「结构视图」会显示每张纸片的折法。
- 示例书《伦敦地图》：每一页的地面都是街道地图，地标立在它的真实位置上，折法按建筑的样子来选：议会大厦是手风琴立面，大本钟和小黄瓜是十字插片，圣保罗大教堂是箱形折，碎片大厦是 V 折，扉页和跨年夜烟花是放射折。每页角落有区域标签卡，前面有一条章节缎带。
- 用照片做书：上传 1–6 张照片，每张照片会被剪成背景页、天际线纸片和前景纸片，并自动加上拉片和翻页卡片。街道、建筑主题的天际线会折成手风琴立面，有棱角的主角用 V 折；远处的纸片自动变淡、偏冷，拉开景深。

在 GitHub Pages 上，新做的书保存在当前浏览器（IndexedDB）里，正文使用你给照片写的说明。在 claude.ai 上打开同一页面时，Claude 会看照片写标题和故事、为每页挑折法，书也会保存到你的 Claude 账户。

没有构建步骤。书架是单文件 `index.html`；3D 书在 `memory.html`，代码在 `books/`（three.js 放在 `vendor/three/`），需要通过本地服务器打开（例如 `python3 -m http.server`），因为用到了 ES 模块。

## 折法

所有站起来的纸片都是平行折（a + h ≤ 52：离书脊的距离 + 高度 ≤ 页高，合上不露出）。在平行折上还可以挂别的折法，它们随书页开合展开、收拢，合上时压平在纸片里：

| `fold` | 折法 | 参数 |
|---|---|---|
| （无） | 平行折 | `x, w, a, h` |
| `cross` | 十字插片 | `depth`, `side` |
| `box` | 箱形折 | `depth`, `sideH`, `side`, `sideColor`, `roofColor` |
| `v` | V 折 | `angle` |
| `accordion` | 手风琴立面 | `segs`, `angle` |
| `fan` | 放射折 / 烟花 | `rays`, `ray(k)`, `spread`, `rayW`, `burst` |

拉片可以用 `ctx.unfold(id, v)` 控制折法展开的程度。
