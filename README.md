# 纸上城市 · Pop-up books

一个可以在浏览器里翻的立体书书架。

- 示例书《伦敦》：舞台式立体书，纸片按平行折的几何关系随书页开合立起、折平；页面上可以直接拉拉片、掀翻页、转转盘、点机关；「结构视图」会显示每张纸片的折法。
- 用照片做书：上传 1–6 张照片，每张照片会被剪成背景页、天际线纸片和前景纸片，并自动加上拉片和翻页卡片。

在 GitHub Pages 上，新做的书保存在当前浏览器（IndexedDB）里，正文使用你给照片写的说明。在 claude.ai 上打开同一页面时，Claude 会看照片写标题和故事，书也会保存到你的 Claude 账户。

单文件网页，没有构建步骤：直接打开 `index.html` 即可。
